# Telemetry — статистика и экспорт чатов Telegram

**Текущая версия: 2.7.3**

Android-приложение для работы с Telegram-аккаунтом через официальный
[TDLib](https://core.telegram.org/tdlib) (MTProto, полный доступ к аккаунту —
не бот-API). Ключи `api_id` / `api_hash` берутся на
[my.telegram.org](https://my.telegram.org) → *API development tools* и вводятся
прямо в приложении при первом входе; они сохраняются только на устройстве.

Готовый APK последней сборки — в разделе
[Releases → latest](https://github.com/Sonnik73/Telemetry-telegram/releases/tag/latest)
(файл `app-debug.apk`, ставится поверх предыдущей версии). На каждом экране есть
кнопка «ℹ» с описанием его функций, а разделы открываются из бокового меню (☰).

## Возможности

- **Вход в аккаунт**: api_id/api_hash → номер телефона → код → пароль 2FA.
- **Боковое меню (☰) и подсказки**: разделы открываются из выдвижной панели, на
  каждом экране кнопка «ℹ» кратко описывает его возможности.
- **Список чатов**: все диалоги (личные, группы, каналы) с поиском и числом участников.
- **Статистика чата**:
  - быстрые счётчики по типам сообщений (всего, фото, видео, файлы, музыка,
    голосовые, видеосообщения, GIF, ссылки) — мгновенно, силами сервера;
  - полное сканирование истории: объём медиафайлов в КБ/МБ/ГБ/ТБ по категориям,
    топ-10 участников, самый активный день, среднее число сообщений в день,
    количество символов текста; с прогрессом, отменой и ограничением по датам.
- **Экспорт истории**: весь чат или период (в т.ч. один день) в **JSON**
  (машиночитаемый, в духе экспорта Telegram Desktop) или **HTML** (читаемый в
  браузере). Файл сохраняется через системный диалог «Сохранить как». Медиа —
  метаданными (тип, имя файла, размер, длительность) или, по желанию,
  **полной выгрузкой файлов** в папку `files/` рядом с экспортом; HTML тогда
  показывает фото/видео/аудио прямо на странице. Галочками «Что выгружать»
  можно оставить только нужные типы (например, только фото и видео) — остальное
  в файл не попадёт. Можно задать лимит размера: медиа крупнее указанного
  (в МБ) не скачивается — в экспорт попадают только его метаданные с пометкой.
- **График активности** в статистике чата: сообщения по дням (автоматически
  укрупняется до недель/месяцев), значение бара — по тапу.
- **Сводка по аккаунту**: суммарное число сообщений во всех чатах, разбивка
  по типам чатов и топ-20 самых активных с прогрессом опроса и отменой.
- **Комментарии каналов при экспорте**: для каналов в экспорт можно включить
  комментарии к постам (из группы обсуждений) вместе с их медиа — в HTML они
  выводятся под постом, в JSON вложены в поле `comments`.
- **Автоскачивание медиа**: для выбранных чатов новые фото/видео/файлы
  автоматически сохраняются в выбранную папку в фоне (пока работает трекер).
  Включается на экране статистики чата.
- **Топ слов и эмодзи** в статистике чата (при полном сканировании) плюс
  экспорт всей статистики в **CSV**.
- **Аналитика переписки** в статистике чата (при полном сканировании): сколько
  сообщений отправили вы и сколько собеседник, среднее время ответа с каждой
  стороны, кто чаще начинает разговор, и распределение сообщений по дням недели
  (столбики Пн–Вс).
- **Кто смотрел мои истории** (чего нет в официальном клиенте так подробно):
  список зрителей ваших активных историй — кто посмотрел, когда, с какой
  реакцией, плюс репосты и пересылки. Работает, пока история не истекла.
- **Перевод сообщений** прямо в переписке (кнопка «перевести» у сообщения,
  средствами TDLib) и **догрузка старых сообщений** при прокрутке вверх.
- **Отслеживание ключевых слов**: фоновый сборщик проверяет новые сообщения во
  всех чатах и каналах, где вы состоите; при совпадении со словом/фразой —
  пуш-уведомление и запись в журнал (с чатом, отправителем и датой, тап
  открывает чат). Совпадение — по вхождению без учёта регистра, в тексте и
  подписях к медиа. Журнал можно выгрузить в CSV.
- **Тёмная тема и настройки**: экран «Настройки» — выбор темы (как в системе,
  светлая, тёмная), применяется сразу ко всему приложению.
- **Отправка медиа в диалоге**: кнопка «скрепка» отправляет выбранное фото,
  видео или файл собеседнику (наравне с текстом).
- **Контакты: удалили/заблокировали** (чего нет в официальном клиенте): опрос
  адресной книги — кто удалил аккаунт и у кого вас нет в контактах (человек убрал
  вас из контактов или заблокировал; это эвристика). Тап открывает досье.
- **Экспорт архива в CSV**: журнал удалённого/правок выгружается кнопкой на
  экране архива.
- **Глобальный поиск сообщений**: поиск по всем чатам (серверный, TDLib) —
  список результатов с названием чата, отправителем и датой; тап открывает
  диалог нужного чата. Кнопка «лупа» в списке чатов.
- **Перехват одноразовых медиа** (чего нет в официальном клиенте): когда включено,
  входящие «самоуничтожающиеся» фото/видео/голосовые автоматически сохраняются в
  приватную память приложения до того, как исчезнут; их можно открыть или сохранить
  в галерею. Работает, пока запущен фоновый трекер; секретные чаты не поддерживаются.
- **Календарь из чатов**: находит в недавно полученных сообщениях упоминания дат и
  времени («завтра в 18:00», «25.12», «5 января») и собирает их в список ближайших
  событий; тап открывает чат. Эвристика — возможны пропуски.
- **Статистика личных чатов**: суммарно по всем личным (один-на-один) чатам — число
  сообщений, среднее на чат, непрочитанные, топ собеседников по сообщениям и по
  непрочитанным.
- **Граф связей контактов** (чего нет в официальном клиенте): строит социальную
  сеть — две точки соединены, если у контактов есть общая с вами группа
  (`getGroupsInCommon`). Силовая раскладка, движение пальцем и масштаб щипком;
  видно кластеры знакомств.
- **Детектор «печатает…»** (чего нет в официальном клиенте): фоновый сборщик
  ловит, кто и когда начал печатать / записывать голосовое / отправлять медиа во
  всех чатах, где вы состоите, — даже не открывая их (`chatActionUpdates`).
  Журнал событий с именем, чатом, действием и временем; тап открывает чат.
- **Поиск по номеру телефона** (чего нет в официальном клиенте так удобно):
  находит аккаунт Telegram по номеру (`searchUserByPhoneNumber`), если владелец
  не скрыл себя от поиска; тап открывает досье.
- **Последний онлайн всех контактов**: единый дашборд со временем последнего
  захода каждого контакта, сортировка «кто был недавно»; точное время — у тех,
  кто не скрыл его в приватности. Тап открывает досье.
- **Чистильщик следов**: массовое удаление ВАШИХ сообщений «у всех» — в выбранном
  чате или во всех сразу (для групп — серверное удаление по отправителю, для
  лички — постранично ваши исходящие). Удаляются только ваши сообщения;
  действие необратимо, с подтверждением.
- **Истории контактов** (чего нет в официальном клиенте): активные истории ваших
  контактов с возможностью скачать фото/видео — в том числе из историй, где автор
  запретил сохранение (приложение качает медиа напрямую через TDLib). Просмотр
  здесь не помечает историю как «просмотренную» у автора; истории видны, пока не
  истекли (обычно 24 ч).
- **Сохранение «запрещённого» медиа**: во всех экранах просмотра (галерея чата,
  диалог) кнопка сохранения скачивает файл через TDLib, поэтому работает и в
  чатах/каналах с запретом пересылки и сохранения — ограничение официального
  клиента не применяется.
- **Галерея медиа чата**: сетка всех фото и видео чата (подгружается по мере
  прокрутки), тап открывает во внешнем просмотрщике/плеере, кнопка «скачать всё»
  сохраняет все загруженные медиа в выбранную папку.
- **Архив удалённого и правок** (чего нет в официальном клиенте): фоновый
  сборщик кэширует входящие сообщения и ловит события удаления/редактирования —
  показывает текст удалённых «у всех» сообщений и историю правок (было → стало),
  с поиском по тексту и фильтром по чату. Можно включить пуш-уведомления о
  каждом удалении/правке в реальном времени (значок колокольчика на экране архива).
- **Досье на контакт**: один экран на человека — профиль, bio, дата рождения,
  число аватарок и общих групп, онлайн-статус (из трекера), история смен
  имени/юзернейма/фото и его удалённые/изменённые сообщения. Открывается из
  онлайн-трекера и из списка дней рождения.
- **Дни рождения контактов**: опрашивает контакты и показывает у кого когда день
  рождения, отсортировано по ближайшим (если контакт указал дату и не скрыл её).
- **Диалог со скрытым чтением**: открыть переписку прямо в приложении. В
  «скрытом режиме» история грузится без отметки о прочтении — собеседник не
  видит, что вы прочитали (галочки не меняются). Переключатель «глаз» выключает
  режим: сообщения помечаются прочитанными и появляется поле ввода для ответа
  (обычная отправка). Реальное время: новые сообщения подтягиваются сразу.
  Медиа видно прямо в переписке: фото/видео/стикеры показываются превью, файлы
  и аудио — строкой; тап по медиа (или кнопка «открыть») скачивает файл и
  открывает его во внешнем просмотрщике — фото на весь экран, видео/аудио
  проигрываются, документы открываются подходящим приложением. Рядом кнопка
  сохранения файла.
- **Геотрекинг** (чего нет в официальном клиенте): когда контакт транслирует
  геопозицию в чате, приложение показывает его точку на карте (OpenStreetMap,
  без сторонних SDK) со стрелкой направления и кругом точности, обновляя её сама
  по мере движения — через события TDLib, без опроса. Каждая точка пишется в
  локальный трек: маршрут линией, пройденное расстояние, средняя и максимальная
  скорость, длительность. Карта двигается свайпом и масштабируется щипком
  (кнопка ⌖ возвращает слежение за точкой). Маршрут сохраняется в файл **GPX**
  (открывается в любых картах). Запустить трансляцию за человека нельзя — только
  смотреть ту, что он включил сам.
- **Онлайн-трекер** (чего нет в официальном клиенте): наблюдение за
  присутствием выбранных контактов. Пуш-уведомление, когда человек появляется
  в сети; статистика — время «в сети» за 7 дней, число и длительность сессий,
  распределение активности по часам суток, журнал последних сессий. Работает в
  фоне через foreground-сервис (иконка в шторке), пока в списке есть хотя бы
  один контакт; переживает перезагрузку. Точное время «был в сети» доступно,
  только если человек не скрыл его в настройках приватности Telegram.
- **Блокировка входа**: опциональный PIN-код (хранится на устройстве только в
  виде солёного PBKDF2-хеша) и разблокировка по отпечатку/лицу. Приложение
  запрашивает код при запуске и после сворачивания; при включённом замке окно
  скрыто от скриншотов и превью «недавних» (FLAG_SECURE). Включается на экране
  «Аккаунт».
- **Шифрование данных «в покое»**: локальная база TDLib (ключи сессии и кэш
  сообщений) шифруется ключом, обёрнутым в аппаратный Android Keystore, — на
  устройстве не лежит открытая копия сессии. Существующая база мигрирует
  автоматически, повторный вход не требуется.
- **Аккаунт**: профиль, объём локального кэша TDLib, топ чатов по размеру кэша,
  блокировка входа, выход из аккаунта.

## Безопасность

Приложение держит у себя ключи сессии Telegram и кэш переписки, поэтому данные
защищаются «в покое». Ничего не уходит с устройства: нет аналитики, нет своих
серверов, сеть — только TDLib напрямую к Telegram.

| Что | Как защищено |
| --- | --- |
| Сессия TDLib и кэш сообщений | Шифруется (`databaseEncryptionKey`) ключом, обёрнутым в аппаратный Android Keystore |
| Перехваченные одноразовые медиа | AES-256-GCM тем же ключом из Keystore |
| Отчёты о крашах | Шифруются (`last_crash.enc`) |
| Временные копии для внешнего просмотра | Стираются при каждом запуске и кнопкой в «Настройках» |
| PIN-код | Солёный PBKDF2-HMAC-SHA256 (120 000 итераций), сравнение за постоянное время |
| Перебор PIN | Блокировка после 4 неудач: 30 с → 15 мин, переживает перезапуск |
| Экран приложения | `FLAG_SECURE` при включённом замке (скрыт от скриншотов и «недавних») |
| Вывоз данных с устройства | Запрещены облачный бэкап и перенос «устройство→устройство» |
| Запросы к локальной БД | Пользовательский текст только через параметры — инъекции невозможны |

Ключ шифрования генерируется на устройстве и оборачивается неизвлекаемым ключом
Android Keystore, поэтому копия файлов приложения на другом устройстве
бесполезна. Существующая незашифрованная база мигрирует автоматически при
обновлении — повторный вход не требуется.

**Осознанно не сделано** (с обоснованием, а не по недосмотру):

- **Криптопривязка биометрии** (`CryptoObject`) — защищает только от
  рутованного/хукнутого устройства, но заметно усложняет разблокировку. Реальная
  защита данных обеспечена шифрованием на ключе из Keystore, а не экраном замка.
- **Ротация ключа подписи** — ключ в репозитории общий и намеренно «одноразовый»
  (нужен, чтобы обновления ставились поверх). Смена ключа сломала бы установку
  поверх, а старый всё равно остаётся в истории git. Для публикации в сторе
  понадобится отдельный секретный ключ.
- **R8 / обфускация** — риск сломать нативный TDLib (JNI) при нулевой пользе:
  секретов в коде нет, `api_id`/`api_hash` вводит сам пользователь.

**Известное ограничение:** `archive.db` (журнал удалённого и правок, ключевые
слова, события «печатает») пока не зашифрована — лежит в приватной памяти
приложения. Для её шифрования нужен SQLCipher.

## Версии

Нумерация начата с версии **2.0.0** (накопленная функциональность). Дальше:
patch — исправления, minor — новые функции, major — крупные изменения.

- **2.7.3** — безопасность по итогам повторного аудита: временные незашифрованные
  копии медиа стираются при запуске (и кнопкой в «Настройках»); защита PIN от
  перебора (нарастающая блокировка после неудачных попыток, переживает
  перезапуск); отчёт о краше шифруется; явный запрет облачного бэкапа и переноса
  «устройство→устройство» (`dataExtractionRules`).
- **2.7.2** — перехваченные одноразовые медиа теперь шифруются на диске
  (AES-256-GCM ключом из Android Keystore); расшифровка происходит только при
  просмотре/сохранении.
- **2.7.1** — безопасность: база TDLib (сессия и кэш) теперь шифруется «в покое»
  ключом из аппаратного Android Keystore (существующая база мигрирует
  автоматически, вход не сбрасывается); при включённом замке окно помечается
  FLAG_SECURE (скрыто в скриншотах и «недавних»); PIN хранится как
  солёный PBKDF2-хеш (старые SHA-256-хеши проверяются и обновляются).
- **2.7.0** — перехват одноразовых (самоуничтожающихся) медиа с автосохранением;
  календарь событий из недавних сообщений (даты/время → список ближайших);
  статистика по всем личным чатам с топами.
- **2.6.2** — в графе связей практически неограниченный зум, чтобы «расклеить»
  плотные скопления точек и рассмотреть отдельные связи.
- **2.6.1** — открытие бокового меню свайпом от левого края экрана; само меню
  теперь прокручивается, если пунктов больше, чем помещается на экране.
- **2.6.0** — пять «интел»-функций: граф связей контактов (общие группы),
  детектор «печатает…» по всем чатам (фоновый журнал действий), поиск по номеру
  телефона, дашборд «последний онлайн» всех контактов, чистильщик следов
  (массовое удаление своих сообщений в чате или везде).
- **2.5.0** — «Истории контактов»: просмотр и скачивание активных историй
  контактов, включая истории с запретом сохранения (медиа качается напрямую
  через TDLib). Сохранение «запрещённого» медиа в чатах/каналах с защитой
  контента и так работало через галерею и диалог — это отражено в описании.

## Сборка

Требуется Android Studio (или Android SDK 35 + JDK 17+). Всё остальное —
обычный Gradle-проект:

```bash
./gradlew :app:assembleDebug
```

TDLib подключается готовым артефактом
[`dev.g000sha256:tdl-coroutines`](https://central.sonatype.com/artifact/dev.g000sha256/tdl-coroutines)
(TDLib 1.8.66 с нативными библиотеками под все ABI) — собирать C++ вручную не нужно.

Минимальная версия Android — 8.0 (API 26).

## Структура

| Путь | Назначение |
| --- | --- |
| `td/TelegramClient.kt` | Обёртка над TDLib: параметры, машина состояний авторизации |
| `data/ChatRepository.kt` | Загрузка списка чатов, имена отправителей |
| `stats/StatsEngine.kt` | Быстрые счётчики и глубокое сканирование истории |
| `export/ChatExporter.kt` | Потоковый экспорт в JSON/HTML с разворотом в хронологию |
| `ui/*.kt` | Экраны на Jetpack Compose (вход, чаты, статистика, экспорт, аккаунт) |

## Замечания

- Полное сканирование большого чата занимает время: TDLib отдаёт историю
  страницами по ~100 сообщений; при выходе с экрана скан отменяется.
- «Быстрые» счётчики недоступны в некоторых чатах (тогда показывается «—»),
  полное сканирование работает всегда.
- Секретные чаты отключены (`useSecretChats = false`) — приложение только
  читает данные.
